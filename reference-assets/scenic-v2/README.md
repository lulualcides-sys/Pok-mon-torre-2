Source: https://opengameart.org/content/lpc-trees — [LPC] Trees Mega-Pack by bluecarrot16 and the authors listed in the unabridged `CREDITS.txt`.
License: CC-BY-SA 3.0, https://creativecommons.org/licenses/by-sa/3.0/legalcode.

`trees-green.png` is copied unmodified from lpc-trees.zip. SHA256: `694e19b641cb2b2ade5864e9a7bbf145a6c23103361324943b4e1f47a6d83ea2`.
1024×1024 RGBA, 185501 bytes. Phaser frame `grove-v2` selects [0,0,64,64]; rendering uses nearest filtering at integer scale. No native Pokémon/battle image is edited or replaced. The atlas and credits are copied to assets/ui/scenic; credits are accessible from the external campaign options screen.

Arsenal create-game-assets asset_report.py: PASS, alpha present, no format/size problems. The whole atlas uses 137 colours; no quantization was applied to the artists' source.

Other references inspected but not redistributed: FireRed Cerulean (existing project reference), Tuxemon official screenshot (layout/contrast), Valyria Tear village illustration (architecture). Godot OpenRPG banner was rejected as a visual reference because its vector style differs. Puny World was tested then rejected at card scale; not the final tree source.
