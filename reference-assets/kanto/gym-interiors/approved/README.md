# Background images for Kanto gym interiors

This directory is intentionally empty of PNG files until the eight individual
background illustrations exist. The runtime uses the existing functional gym
renderer while a background is missing.

**Do not bake** NPCs, gym leaders, Pokémon aces, labels, icons or interactive
buttons into these images. The native Phaser layer draws these separately.

See [the exact artwork contract](../../../../docs/GINASIOS-FUNDO-IMAGEM-PHASER-T38.md)
for required dimensions, all eight filenames, precise NPC/ace foot positions,
safe UI areas, asset provenance and review/merge requirements.

Images placed here are a *build-time inclusion choice*, not blanket user
approval of Kanto visual quality. All visual PRs remain DRAFT pending
complete-map review through the Elite Four.
