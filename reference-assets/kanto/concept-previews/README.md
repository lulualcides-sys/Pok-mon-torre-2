# Kanto concept-sheet previews

These 11 WebP images are compact, downsampled **references** to the project's AI-generated concept sheets. They are **not** separate sprites, not a tile atlas and not installed in game runtime. The full-resolution PNG source images are maintained in the conversation bundle `kanto_conceptos_originais_2026-11-01.zip` instead of bloating the game repository with 37 MB of uncut illustrative boards. See `manifest.json` for per-image SHA-256, original file name and preview dimensions.

**Do not render these boards directly in Phaser.** They contain poster layouts, captions, mixed scene views and sometimes fictional status labels. Generate/cut pixel-grid components only after artistic and IP review. Separate production candidates are under `../pixel-library-v2/`.
