# Personal Alpha 0.71.3 visual fallback experiment

Script: `tools/pokearena/stage-personal-alpha0713.py`.

The official Alpha 0.71.3 is confirmed via `src-5ccc174cb8/config.js`. Its 19 inaccessible official costume variants can be **approximated** using alternative SpriteCollab base sheets, with pixel-art recoloring, and source credits and SHA256 per generated PNG.

This script **does not copy the original 19 inaccessible sprites** and makes no fidelity or redistribution claim. It writes only into a temporary `site-capture` copy in GitHub Actions. The proposed public build remains blocked when artist permissions are unknown; `_site` is merely a CI diagnostic. The prior approved Pages build stays untouched.

For private debugging this enables testing original 0.71.3 mechanics on a fully renderable source **if all external reference assets load**. For release, original sprites or properly licensed originals and full browser QA remain necessary.
