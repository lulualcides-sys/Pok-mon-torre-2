2. Criar spritesheets/tilemaps modularizados e pontos de interação Phaser: cena, caminhos, construções, grama, treinadores e objetos.
3. Manter campanha até Brock: Route 1, Viridian, Viridian Forest, Route 2, Pewter, ginásio.
4. Construir UI de loja com ícones e TM usando sprites próprios ou arquivos com permissões adequadas; não substituir arte aprovada.
5. Verificar permissões antes de redistribuir assets extraídos de Pokémon FireRed / LeafGreen; recurso público para visualizar não equivale a licença de republicação.
