## Art and integration

Authored in integer pixel matrices and rendered in Phaser/WebGL, following
Arena 2D's small silhouettes, controlled palette, short anticipation and clear
impact. No new Canvas2D effects, smooth vector circles, CSS shapes or video.
Twelve visual poses, several shape families, per-move trajectories. Melee
moves physically advance/contact/return. Ground eruption has a fixed aimed
warning, so the opponent can move out of it. Other ranged moves use swept
manual-aim hit tests, with no retargeting. Distant melee does not deal damage.

Shared existing code: contactDash and the new-projectile Clash adapter. Native
art is untouched. Pixel silhouettes, impact and debris are additive. Draining
moves heal half actual HP lost only after the returning energy reaches the
caster. Multi-hit moves roll 2–5 shots; each shot can physically miss.

The batch is **implemented, not visually approved**. All previous approvals
remain true. The new definitions carry approved:false and appear under NEW.

## Statistics and explicit arena adaptations

Power, category, accuracy and PP use the main-series reference data listed in
each definition (https://pokemondb.net/move/all and per-move URLs). Arena damage
is normalized as power/5, in line with the established custom move entries;
PP is metadata (the existing arena uses energy/cooldowns). Physical contact and
secondary effects occur only after real hits; no extra elemental status is
silently generated from the native ultimate slot.

The real-time engine has common attack/defense, not a complete independent
Attack/Sp. Atk/Defense/Sp. Def system. Defense drops use native `defBaja`; Acid
Spray lasts longer than Acid's chance-based drop. Ancient Power/Silver Wind use
the native temporary power/speed/defense buff. Poison Fang uses a stronger,
longer native poison, not an exact turn-based escalating toxic counter.
Mud Bomb's accuracy debuff affects these new attacks only, to avoid changing
approved native attack mechanics. These are explicit arena adaptations, not a
claim of cartridge-perfect competitive mechanics. Ice Fang's freeze/flinch
and Poison Jab/Sludge poison use separate hit-conditioned rolls. Fury Cutter
builds up to 4x on consecutive timely hits and resets on miss/another batch move.
